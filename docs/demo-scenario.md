# NexWatch Demo Scenario

## Objective

Demonstrate that NexWatch can maintain reliable structured web
data when the monitored website changes.

## Demo Flow

### 1. Healthy Source

Show a public website being collected through a custom
Bright Data Scraper Studio scraper.

### 2. Structured Output

Show the extracted records entering NexWatch.

### 3. Health Monitoring

Show extraction health and field completeness.

### 4. Website Change

Demonstrate a controlled structural change to the source.

### 5. Failure Detection

Show the extraction quality dropping.

### 6. Self-Healing

Trigger Bright Data scraper self-healing.

### 7. Validation

Compare the repaired output against the expected data contract.

### 8. Recovery

Show the extraction returning to a healthy state.

### 9. Intelligence

Show how the recovered data powers a useful downstream insight.
